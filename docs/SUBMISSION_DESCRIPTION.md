# Submission description

Profily AI turns a developer's static resume into an interactive career profile. Recruiters can ask contextual questions, inspect supporting resume claims or pinned GitHub excerpts, and save an interview brief rather than infer experience from a skills list.

Developers import a PDF and public repositories, review extracted details, and explicitly approve a shareable snapshot. Gemini answers use source citations, exact quote checks and a separate grounding review. Repository observations are distinguished from personal contributions; insufficient evidence is disclosed. Recruiters can use browser voice or text, ask follow-ups, export interview PDFs, and compare job requirements qualitatively against the supplied evidence. Analytics reflect recorded activity, without candidate rankings.

The no-sign-in judge walkthrough uses a clearly fictional candidate and real Express repository evidence. It never claims that the fictional candidate authored Express.

I used Wispr Flow to dictate development instructions into Codex; Codex assisted implementation, debugging, documentation and verification. Wispr Flow supports our development workflow, not the application's runtime through an API. Runtime voice uses browser speech recognition and speech synthesis. No measured productivity or hiring-outcome improvement is claimed.
